# Public / private boundary

## Public
- Current independent firmware source.
- `secrets.example.yaml` only.
- Architecture, interface, validation summary and safety notes.
- Changelog and trademark/unaffiliated notice.

## Keep private / archival
- Original firmware binaries and dumps.
- Decompilation/disassembly and binary-analysis notebooks.
- PCB photographs/scans, Gerbers and manufacturing reconstruction.
- Full raw field evidence ZIPs unless deliberately sanitized.
- Private IP/network layout beyond installation examples.
- Credentials, tokens and real secrets.

This boundary is intentional: the GitHub repository should be useful for interoperability and independent firmware development without becoming a mirror of vendor assets or internal forensic material.
